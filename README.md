# ねこの水分・トイレ帳

飼い猫の水分摂取量・食事量・排泄などを記録して、グラフやカレンダーで確認できるスマホ向けWebアプリです。

## 主な機能
- 水分：食事に混ぜた水／器から飲んだ水（入れた量−残量−蒸発分）／フード自体の水分、と合計・ml/kg
- 食事量：ドライ・ウェットを別々に、フードごとの水分率を設定可能
- 排泄：小（量・色・血尿・トイレ外）、大（5段階の状態・量・色・血・粘液・異物）
- 嘔吐・体重・投薬/通院・自由記述メモ（すべての記録にメモ可）
- グラフ（7/30/90日）、月カレンダー、獣医さん向けレポート
- 記録にもとづく注意表示（診断ではありません）
- 複数の猫に対応
- バックアップ（JSON）の保存・読み込み、CSV出力
- ホーム画面に追加してアプリのように使えます（オフライン対応）

## データの保存について
記録は **使っている端末のブラウザ内だけ** に保存されます。サーバーには送信されません。
ブラウザのデータ消去・機種変更で消えるため、「設定 → バックアップを保存」で定期的にバックアップしてください。
アプリは7日ごとにバックアップを促します。

## 使い方（iPhone）
Safariで開き、共有ボタン →「ホーム画面に追加」。
